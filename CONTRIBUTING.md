# Contributing to NSBOM

Vielen Dank für Ihr Interesse an der Mitarbeit an NSBOM! Wir freuen uns über Beiträge aller Art.

## Wie Sie beitragen können

### Bug Reports
- Nutzen Sie die GitHub Issues
- Beschreiben Sie das Problem detailliert
- Fügen Sie Code-Beispiele hinzu, wenn möglich
- Geben Sie Ihre Umgebung an (OS, Python-Version, etc.)

### Feature Requests
- Öffnen Sie ein Issue mit dem Label "enhancement"
- Beschreiben Sie den Use Case
- Erklären Sie, warum das Feature nützlich wäre

### Code Contributions

#### Setup für Development
```bash
git clone https://github.com/YemotaY/nsbom.git
cd nsbom
python -m venv dev-env
source dev-env/bin/activate  # Windows: dev-env\Scripts\activate
```

#### Code-Standards
- Verwenden Sie Python 3.8+ Features
- Befolgen Sie PEP 8
- Schreiben Sie deutsche Kommentare (wie im bestehenden Code)
- Fügen Sie Docstrings hinzu
- Testen Sie Ihren Code

#### Pull Request Prozess
1. Fork das Repository
2. Erstellen Sie einen Feature Branch (`git checkout -b feature/amazing-feature`)
3. Committen Sie Ihre Änderungen (`git commit -m 'Add amazing feature'`)
4. Pushen Sie zum Branch (`git push origin feature/amazing-feature`)
5. Öffnen Sie einen Pull Request

#### Code Review
- Alle Pull Requests werden reviewed
- Wir könnten Änderungen vorschlagen
- Nach Approval wird der Code gemerged

## Development Guidelines

### Commit Messages
- Verwenden Sie klare, beschreibende Commit Messages
- Nutzen Sie Deutsch (wie im Rest des Projekts)
- Format: `feat: neue Funktion` oder `fix: behebe Bug`

### Testing
- Testen Sie Ihre Änderungen lokal
- Fügen Sie Tests für neue Features hinzu
- Stellen Sie sicher, dass bestehende Tests weiterhin funktionieren

### Dokumentation
- Aktualisieren Sie die README.md bei API-Änderungen
- Fügen Sie deutsche Kommentare hinzu
- Dokumentieren Sie neue Features

## Community

- Seien Sie respektvoll und konstruktiv
- Helfen Sie anderen bei Issues
- Teilen Sie Ihr Wissen

## Kontakt

Bei Fragen können Sie:
- Ein Issue öffnen
- Eine Discussion starten
- Den Maintainer kontaktieren

Vielen Dank für Ihre Unterstützung!
